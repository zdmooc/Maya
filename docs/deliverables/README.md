# Livrables d’architecture — Maya Interlink Solutions

Ce répertoire contient les livrables produits dans le rôle d’**Architecte Solution Senior**.

## Arborescence par mission

Chaque mission doit utiliser le format suivant :

```text
docs/deliverables/<client-ou-cas>/
├── 01-expression-besoin/
├── 02-contexte-existant/
├── 03-architecture-metier/
├── 04-architecture-fonctionnelle/
├── 05-architecture-applicative/
├── 06-architecture-technique/
├── 07-cloud-onprem/
├── 08-data/
├── 09-securite/
├── 10-ha-pra-pca/
├── 11-sizing-capacite/
├── 12-adr/
├── 13-risques-conformite/
├── 14-dossier-architecture-solution/
└── 15-comite-architecture/
```

## Annexes possibles

- diagrammes Mermaid / PlantUML
- matrice de flux
- matrice d’exigences
- matrice de risques
- RACI
- inventaire des composants
- catalogue API
- backlog des décisions et actions
- FinOps / GreenOps
- preuves et résultats de tests

## Règle importante

Le dépôt étant public, aucun document réel confidentiel de banque, assurance ou client ne doit être commité. Les cas de démonstration utilisent des noms fictifs et des données synthétiques.

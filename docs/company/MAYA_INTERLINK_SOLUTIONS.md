# Maya Interlink Solutions

## Positionnement

**Maya Interlink Solutions** est l’entreprise fictive servant de cadre professionnel au projet Maya.

## Rôle exercé

**Architecte Solution Senior / Architecte Cloud & Platform**

Responsabilités principales :

- cadrer un besoin métier et ses contraintes ;
- analyser l’existant et les dépendances SI ;
- définir l’architecture cible métier, fonctionnelle, applicative et technique ;
- concevoir des architectures on-premise, hybrides et cloud ;
- intégrer OpenShift/Kubernetes, API, data, sécurité, observabilité et résilience ;
- produire les ADR et dossiers d’architecture ;
- présenter les choix en comité d’architecture ;
- challenger coûts, exploitabilité, FinOps et GreenOps ;
- maintenir la traçabilité entre exigences, décisions et solutions.

## Secteurs de simulation

- Banque
- Assurance
- Services financiers
- Industrie
- Secteur public
- Autres SI d’entreprise

## Règles de confidentialité

Les cas utilisés dans ce dépôt sont fictifs. Aucun nom de client réel, secret, identifiant, document confidentiel ou information interne ne doit être publié dans ce dépôt public.
